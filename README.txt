Штаб студенческих отрядов Астраханского ГМУ
Студенческие медицинские отряды (СМО)

Версия подготовлена для публикации на Vercel без GitHub.

Главные файлы:
- index.html — Главная
- about.html — О нас
- teams.html — Наши отряды
- contacts.html — Контакты
- join.html — Вступить в РСО
- teams/* — страницы четырёх отрядов
- data.js — все основные данные сайта
- app.js — общая логика
- style.css — дизайн
- admin/index.html — визуальный редактор data.js
- vercel.json — настройки Vercel
- DEPLOY-VERCEL.txt — инструкция по публикации и обновлениям

Перед финальным запуском нужно заменить заглушки: реальные фото, ФИО,
цифры, достижения, VK, адрес личного кабинета и endpoint анкеты.
