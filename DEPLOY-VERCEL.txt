ШСО Астраханского ГМУ — публикация на Vercel без GitHub
==========================================================

ВАРИАНТ 1. САМЫЙ ПРОСТОЙ ПЕРВЫЙ ЗАПУСК — VERCEL DROP
1. Откройте https://vercel.com/drop
2. Войдите в свой аккаунт Vercel.
3. Перетащите ZIP-архив сайта прямо в окно браузера.
4. Укажите имя проекта, например: shso-astgmu-site
5. Нажмите Deploy.
6. Vercel выдаст адрес вида https://shso-astgmu-site.vercel.app

ВАЖНО
Vercel Drop удобен для первого запуска, но каждый новый Drop создаёт новый проект.
Чтобы потом обновлять ТОТ ЖЕ проект и сохранять тот же адрес без GitHub,
используйте Vercel CLI (вариант 2 ниже).

ВАРИАНТ 2. ОБНОВЛЕНИЕ ТОГО ЖЕ ПРОЕКТА БЕЗ GITHUB — VERCEL CLI
1. Установите Node.js, если его ещё нет: https://nodejs.org/
2. Откройте Терминал / PowerShell.
3. Установите Vercel CLI:
   npm install -g vercel
4. Распакуйте ZIP сайта в обычную папку.
5. Перейдите в эту папку командой cd.
6. Выполните:
   vercel login
7. Затем:
   vercel
   При первом запуске выберите существующий проект или создайте новый.
8. Для публикации в основной адрес используйте:
   vercel --prod

После первого связывания проекта Vercel создаст локальную папку .vercel.
Дальше для обновления сайта достаточно заменить файлы и снова выполнить:
   vercel --prod

ЧТО МЕНЯТЬ В САЙТЕ
- Основные тексты, цифры, ссылки, отряды и комсостав: data.js
- Фотографии: папка assets
- Визуальный редактор данных: /admin/
  Он позволяет отредактировать данные и скачать новый data.js.

ПОСЛЕ РЕДАКТИРОВАНИЯ
1. Замените старый data.js новым.
2. Замените нужные фотографии в assets.
3. Выполните vercel --prod.

АНКЕТА ВСТУПЛЕНИЯ
Сейчас форма работает в демонстрационном режиме.
Позже в data.js в site.joinEndpoint будет указан URL Google Apps Script,
после чего анкеты будут уходить в Google Таблицу.

ЛИЧНЫЙ КАБИНЕТ
В data.js замените:
  cabinetUrl: 'https://lk.example.ru'
на настоящий адрес действующего личного кабинета Vercel.
